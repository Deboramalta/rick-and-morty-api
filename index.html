A história de Rick and Morty

Rick and Morty é uma série de animação que acompanha as aventuras de Rick Sanchez, um cientista extremamente inteligente, e seu neto Morty Smith.

Utilizando invenções tecnológicas e uma arma capaz de abrir portais, os dois viajam por planetas, universos paralelos e dimensões desconhecidas.

A série mistura ficção científica, aventura, comédia e situações inesperadas, explorando as consequências das viagens pelo multiverso.

Sobre o projeto

Este site foi desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Web Front-End.

O projeto utiliza HTML, CSS e JavaScript para consultar a API pública Rick and Morty e apresentar informações dos personagens em cards criados dinamicamente.
